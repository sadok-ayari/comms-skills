# Ministerial correspondence

A letter to a ministry is not an email with Arabic in it. It is a document that a civil servant will forward, a director will summarise, and a minister may read only the first paragraph of. Write for that chain.

## Structure that survives forwarding

1. **Salutation** — `السيدة/ [الاسم] المحترمة،` or `سعادة/ [الاسم] المحترم،` then `السلام عليكم ورحمة الله وبركاته،`
2. **Acknowledgment opener** — thank them for the communication or the guidance. One sentence: `نشكر لكم تواصلكم الكريم وحرصكم المستمر على إنجاح العمل.`
3. **Attachments first when you send documents** — `أولاً: المرفقات` with a one-line description of each. A reader who forwards the file without the body still knows what is inside.
4. **Numbered sections** — `أولاً / ثانياً / ثالثاً` headings. Each section one idea.
5. **The ask** — one ask, in the final paragraph, with a date.
6. **Closing** — `نأمل أن تجدوا في هذه الإيضاحات ما يؤكد حرصنا على التعاون` … `وتفضلوا بقبول فائق الاحترام والتقدير،`

## Tone: soft framing, firm facts

The register is deference, not submission. The substance does not move; only the frame does.

- **No blame, ever.** Not "had approvals moved faster", not "we were not informed". The moment blame is implied, the letter becomes a dispute file.
- **Acknowledge before you limit.** `وإذ نتفهم تماماً الحرص المشترك على سرعة الإنجاز...` then state the constraint.
- **Reframe as a shared goal**, not a complaint: `نعمل جميعاً من أجل هدف واحد`.
- **Every constraint comes with a constructive path.** A refusal without an alternative is a delay dressed as a reply.
- **Effort with the partner, not pressure that failed:** `بذلنا مع الجهة جهوداً حثيثة لتقديم التسليم في موعد أبكر` beats `ضغطنا دون جدوى`.

## Lexicon that softens without weakening

| Blunt | Institutional |
|---|---|
| لا يمكن تجاوزها | إضافية يلزم أخذها في الاعتبار |
| مضاعفة أعباء | زيادة متطلبات |
| تجنباً لأي خلل في التنفيذ | ضماناً لجودة التنفيذ |
| لا يمثل أي إخلال بالتزاماتنا | لا يمس الالتزامات المتفق عليها |
| مدة معتمدة في المعايير | مدة متوافقة مع المعايير المتعارف عليها |

## The document-history argument

When a timeline slips, do not argue about who slowed it down. Reconstruct the dated record instead:

`التاريخ — ما تم الاتفاق عليه — ما تحقق`

Facts do the arguing. Close the section on a commitment, never on the delay: the accelerated schedule, the protected date, the parallel work already underway. `انعكاس موضوعي لهذا المسار الزمني المتراكم` is a stronger sentence than any accusation, and it cannot be answered with anger.

## Responding to a marked-up document

1. Read the comment layer, not the slide or page text. That is where the real asks are.
2. One numbered reply per comment, in their order.
3. Restate a structural instruction as an implementation decision: "we split the table in two, one for X and one for Y."
4. Describe anything removed at their request as `إزالة مؤقتة` (temporary), never as a deletion.
5. Verify every claimed fix against the file before it is sent, and say which ones you could not verify.
6. Send the clean copy, not the working file with the comment threads.

## Checklist before sending

- [ ] Salutation, closing and signature present and correct
- [ ] Zero em-dashes; parentheses instead
- [ ] No Latin words in the Arabic body where an Arabic term exists
- [ ] No senior official named to a junior recipient
- [ ] No accusatory heading; headings are factual
- [ ] One ask, in the last paragraph, with a date
- [ ] Attachments introduced if referenced
- [ ] Every figure matches its source
- [ ] Rendered file checked for right-to-left layout, not just the text

## Pitfalls

- **Softening the facts along with the tone.** The dates and numbers stay exactly as they are; only the framing moves.
- **Apologising for a delay you did not cause**, which accepts responsibility you will be held to later.
- **A long letter that argues.** If the letter needs three pages, the annex is missing.
