# Delivery gate

Everything that embarrasses an institution leaves through the same door: a file sent before anyone read it as the recipient. This is the five-minute pass that door should have had.

## Step 1 — Name the contract

Before checking anything, state what this artefact promises in one line.

- **Brief or one-pager:** verdict in the first line, one page, three sections maximum.
- **Deck:** one message per slide, no slide above 25 words, a source line wherever a number appears.
- **Letter or email:** one ask, in the last paragraph, with a date and an owner.
- **Report:** every figure traced, every recommendation assigned.

If the artefact cannot be summarised in a line, it is not ready, and no amount of checking will fix that.

## Step 2 — The eight-point gate

1. **Owner and version named.** Who produced it, which version, which date.
2. **Recipient and channel correct.** The right person, the right address, the right door — not a distribution list.
3. **One message.** The artefact makes one argument. A second argument becomes an annex.
4. **Language parity**, where two languages exist: numbers, names, commitments, section order.
5. **Every number traced** to a source you can produce on request. No source, no number.
6. **No debris.** No placeholders, tracked changes, internal comments, or `[Info gap]` left visible without a note saying so.
7. **File named and filed.** The name says what it is and when; the copy lives where the team will look for it.
8. **Read-back.** Open the actual file, at the end, and read the first and last paragraph aloud.

## Step 3 — The read-back is not optional

Most delivery failures are not judgement failures; they are file failures. The wrong version, the stale table, the comment still visible, the attached PDF that carries the old logo. Open the file you are about to send and look at it.

## Rules

- **The gate runs before the send, not after.** A gate that reviews what already left is a post-mortem.
- **Item four cannot be passed by eye.** If the Arabic is a translation of the English rather than a parallel composition, parity needs the check, not an impression.
- **One person owns the gate.** Shared ownership of the final read is no ownership.
- **Record the exceptions.** When something ships with a known gap, the gap is named in the covering note. Silent gaps become the counterpart's discovery.

## Output

A verdict, not a paragraph:

```
Delivery: CLEAR
Delivery: BLOCKED — items 5, 6 (three untraced figures; two comments visible)
```

Plus, when blocked, the shortest list of who has to fix what.

## Pitfalls

- Running the gate on the draft instead of the exact file being sent.
- Treating a green gate as an endorsement of the thinking. It certifies that the file is fit to send, not that it should be sent.
- Adding a ninth and tenth check. Eight is already at the edge of what people actually run.
